# Goety & Invasion

An official addon mod that bridges [Goety] and [Illager Invasion], allowing players to utilize the unique Illagers as servants.

## 📖 About
This mod brings the unique Illagers from Illager Invasion into the servant roster of Goety. 

## 🔧 Requirements
- Minecraft 1.20.1 (1.21.1 port in progress)
- [Goety]
- [Illager Invasion]
- Forge / NeoForge

## 🚀 Installation
1. Install Minecraft Forge/NeoForge.
2. Drop the `Goety & Invasion` jar file into your `mods` folder along with the required dependencies.
3. Launch the game!
